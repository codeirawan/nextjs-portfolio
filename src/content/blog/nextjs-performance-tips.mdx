# 10 Tips Mengoptimalkan Performa Next.js untuk Production

Next.js adalah framework React yang powerful, tapi untuk mendapatkan performa terbaik di production, ada beberapa teknik optimasi yang perlu Anda ketahui. Dalam artikel ini, kita akan membahas 10 tips praktis yang bisa langsung Anda implementasikan.

## 1. Bundle Analysis dengan Next.js Bundle Analyzer

Sebelum mengoptimalkan, kita perlu tahu apa yang menyebabkan bundle size besar. Install bundle analyzer:

```bash
npm install @next/bundle-analyzer
```

Kemudian tambahkan konfigurasi di `next.config.js`:

```javascript
const withBundleAnalyzer = require("@next/bundle-analyzer")({
  enabled: process.env.ANALYZE === "true",
});

module.exports = withBundleAnalyzer({
  // konfigurasi Next.js lainnya
});
```

Jalankan analisis dengan:

```bash
ANALYZE=true npm run build
```

## 2. Implementasi Dynamic Imports

Dynamic imports memungkinkan code splitting otomatis. Gunakan untuk komponen yang tidak perlu di-load immediately:

```jsx
import dynamic from "next/dynamic";

const HeavyComponent = dynamic(() => import("../components/HeavyComponent"), {
  loading: () => <p>Loading...</p>,
  ssr: false, // jika komponen tidak perlu SSR
});

export default function Page() {
  return (
    <div>
      <h1>My Page</h1>
      <HeavyComponent />
    </div>
  );
}
```

## 3. Optimasi Images dengan Next.js Image Component

Next.js Image component memberikan optimasi otomatis:

```jsx
import Image from "next/image";

export default function BlogPost() {
  return (
    <Image
      src="/hero-image.jpg"
      alt="Hero Image"
      width={1200}
      height={630}
      priority // untuk above-the-fold images
      placeholder="blur"
      blurDataURL="data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAAAQ..."
    />
  );
}
```

## 4. Konfigurasi Caching Headers

Optimalkan caching dengan mengatur headers di `next.config.js`:

```javascript
module.exports = {
  async headers() {
    return [
      {
        source: "/_next/static/(.*)",
        headers: [
          {
            key: "Cache-Control",
            value: "public, max-age=31536000, immutable",
          },
        ],
      },
      {
        source: "/images/(.*)",
        headers: [
          {
            key: "Cache-Control",
            value: "public, max-age=31536000",
          },
        ],
      },
    ];
  },
};
```

## 5. Implementasi ISR (Incremental Static Regeneration)

ISR memberikan balance antara static generation dan dynamic content:

```jsx
export async function getStaticProps() {
  const data = await fetchData();

  return {
    props: { data },
    revalidate: 3600, // revalidate setiap 1 jam
  };
}
```

## 6. Tree Shaking dan Import Optimization

Hanya import fungsi yang benar-benar dibutuhkan:

```javascript
// ❌ Buruk - import seluruh library
import _ from "lodash";

// ✅ Bagus - import fungsi spesifik
```

## 7. Preload Critical Resources

Gunakan `next/head` untuk preload resource penting:

```jsx
import Head from "next/head";

export default function Page() {
  return (
    <>
      <Head>
        <link
          rel="preload"
          href="/fonts/inter-var.woff2"
          as="font"
          type="font/woff2"
          crossOrigin=""
        />
        <link rel="preconnect" href="https://api.example.com" />
      </Head>
      {/* konten page */}
    </>
  );
}
```

## 8. Optimasi Database Queries

Untuk API routes, optimasi query database:

```javascript
// api/posts/[slug].js
export default async function handler(req, res) {
  const { slug } = req.query;

  // ✅ Select hanya field yang dibutuhkan
  const post = await db.post.findUnique({
    where: { slug },
    select: {
      id: true,
      title: true,
      content: true,
      publishedAt: true,
      // jangan select semua field
    },
  });

  // Implementasi caching
  res.setHeader("Cache-Control", "s-maxage=60, stale-while-revalidate");
  res.json(post);
}
```

## 9. Service Worker untuk Caching

Implementasi service worker untuk offline caching:

```javascript
// public/sw.js
const CACHE_NAME = "my-app-v1";
const urlsToCache = ["/", "/static/css/main.css", "/static/js/main.js"];

self.addEventListener("install", (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(urlsToCache)),
  );
});
```

## 10. Monitoring dan Analytics

Setup monitoring untuk track performa real-time:

```jsx
// pages/_app.js
import { getCLS, getFID, getFCP, getLCP, getTTFB } from "web-vitals";

function sendToAnalytics(metric) {
  // Kirim ke analytics service
  gtag("event", metric.name, {
    value: Math.round(
      metric.name === "CLS" ? metric.value * 1000 : metric.value,
    ),
    event_label: metric.id,
    non_interaction: true,
  });
}

export function reportWebVitals(metric) {
  sendToAnalytics(metric);
}
```

## Kesimpulan

Optimasi performa Next.js memerlukan pendekatan holistik. Mulai dengan menganalisis bundle size, implementasikan lazy loading, optimalkan images, dan jangan lupa monitoring.

Dengan menerapkan tips-tips di atas, aplikasi Next.js Anda bisa mencapai score Lighthouse 90+ dan memberikan user experience yang optimal.
